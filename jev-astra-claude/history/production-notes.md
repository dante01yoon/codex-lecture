# 제작·실행 이력

## 실습 기록

- 코딩 에이전트: 실제 Codex CLI와 Claude Code를 순서대로 사용해 앱 구현과 검토를 진행했습니다. 재현용 요청문은 `../practice-kit/inputs/`에 있습니다.
- Jev 연결: 로컬 Node.js 앱 서버가 TypeSafe API에 요청합니다. API 키는 서버 프로세스에서만 읽으며, 저장소와 브라우저로 보내지 않습니다.
- 실습 데이터: 합성 고객 문의 17건의 요청·응답을 공유용으로 정리해 `../practice-kit/evidence/jev-requests.sanitized.jsonl`에 포함했습니다. 이 파일은 과거 실행을 확인하는 기록이며 새 실행 결과를 재생하지 않습니다.
- 개인정보 경계: 개인 키, 로그인 상태, 원시 Codex/Claude 터미널 세션, 음성 프로필은 배포 자료에서 제외했습니다.
