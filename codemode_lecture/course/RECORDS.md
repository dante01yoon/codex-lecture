# 실행 기록은 무엇이고 어디서 보나요?

실행 기록은 요청 이후 어떤 도구가 호출됐고 어떤 결과를 돌려줬는지 남은 작업 이력입니다. 프로그램 문법을 공부해야만 이 강의를 따라갈 수 있는 것은 아닙니다. 먼저 입력 프롬프트와 결과를 비교하고, 처리 방식이 궁금할 때 코드를 열어보세요.

## 이 강의의 웹페이지에서 보기

이 저장소의 `codemode_lecture` 폴더에서 다음을 실행합니다.

```sh
python3 production/viewer.py
```

브라우저에서 `http://127.0.0.1:8769`를 엽니다.

1. **시작하기 → 기록 보는 법**: 기록의 뜻과 파일 링크를 확인합니다.
2. **시작하기 → 실행 확인**: `1 · 요청`, `2 · 실제 코드`, `3 · 반환 결과`를 차례로 누릅니다.
3. 코드 화면의 **두 조회를 묶기 / 폴더와 연도 조회 / 결과 꺼내기** 버튼으로 핵심 부분만 강조해 볼 수 있습니다.
4. 서비스 조사·리뷰·주간 보고서·GitHub에서는 **실제 실행 코드** 탭을 누릅니다. 코드 줄을 클릭하면 그 줄이 강조됩니다.

이 웹페이지는 공식 Codex 앱의 화면이 아닙니다. 실제 CLI 실행 기록에서 필요한 부분을 발췌해 읽기 쉽게 표시한 강의용 뷰어입니다. 저장된 기록을 여는 것만으로 새 Codex 실행이 발생하지 않습니다. 각 실습의 ‘이 프롬프트로 Codex 실제 실행’ 버튼을 눌러야 새 실행이 시작되며 계정 사용량이 소모됩니다.

## 사전 확인은 무엇을 했나요?

2026-09-13 미국 동부 시간에 다음 요청으로 실제 실행했습니다. 한국어는 원래 영어 요청의 설명용 번역이며, 원문은 `assets/preflight-record.json`에 함께 있습니다.

> Code Mode에서 현재 폴더(pwd)와 올해 연도(date +%Y)를 조회하는 두 작업을 Promise.all로 묶고 결과를 출력해줘. 다른 파일은 읽지 마.

코덱스가 생성한 JavaScript는 두 `exec_command` 호출을 `Promise.all`로 묶고 결과를 출력했습니다. 원본의 `custom_tool_call`에 저장된 실제 exec 입력이 웹페이지의 코드와 일치하며, 같은 `call_id`의 `custom_tool_call_output`에서 작업 폴더와 `2026`을 반환한 것을 대조했습니다. 이 검증은 실제 Code Mode 실행 확인이며 서버 병렬 처리나 속도 우월성 벤치마크가 아닙니다.

## 파일로 보기

- `assets/preflight-record.json`: 사전 확인 요청, 실제 exec 입력, 반환값, 확인 범위. 웹페이지 링크로 열거나 텍스트 편집기에서 열 수 있습니다.
- `assets/preflight-code.json`: 같은 사전 확인의 코드만 보존한 파일.
- `assets/02_reviews.json` 등: 각 실습의 요청, 실행 코드와 도구 출력, 최종 답변. `events`에서 `type: code`인 항목이 실제 생성된 코드입니다.
- `qa/independent-checks.json`: 리뷰 숫자와 업무 연결 결과를 합성 원본과 따로 대조한 기록.

## 심화: 원본 CLI 세션과 뷰어는 어떻게 연결되나요?

이번 촬영 환경의 원본 세션 파일은 사용자 폴더의 `~/.codex/sessions/날짜/rollout-….jsonl`에 저장됐습니다. JSONL은 사건마다 한 줄씩 적은 텍스트 형식입니다. 앱·설정에 따라 저장 위치나 노출 방식이 다를 수 있어, 모든 앱에 ‘실행 코드’라는 메뉴가 있다고 가정하지 않습니다.

실습 실행 도우미는 `codex exec --json`으로 받은 작업 ID에 해당하는 세션만 찾아, `exec` 도구 입력과 도구 반환값을 추려 `assets/<실습 이름>.json`에 저장합니다. 뷰어는 그 발췌 파일을 표시합니다. ‘준비 완료’라는 최종 답변이나 일반 명령 실행 성공만으로 Code Mode가 쓰였다고 판정하지 않습니다.

원본 세션 전체에는 개인 대화와 다른 정보가 포함될 수 있어 배포하지 않습니다. 제공 자료에는 이번 실습의 필요한 호출과 결과만 들어 있습니다. 코드 읽기를 생략해도 결과의 숫자·출처·실패 여부는 확인하세요.

## 공개 배포본의 편집 범위

사전 확인 코드와 반환값의 개인 로컬 절대 경로는 `/path/to/codemode_lecture`로 치환했습니다. 이 표시는 실제로 입력할 경로가 아닙니다. 리뷰·GitHub 기록에서 강의와 무관한 설치 도구 목록은 생략 표시했습니다. 실제 처리 코드와 실습 결과는 유지했습니다.
